# Revorix Engineering Website

Production-ready static website for **Revorix Engineering** at **https://revorixengineering.com**.

## Site structure

- Multi-page static HTML website (no npm/build step)
- Responsive custom CSS and lightweight vanilla JavaScript
- Local portfolio imagery and Fiverr review screenshots
- SEO metadata, OpenGraph image, sitemap, robots.txt and structured data
- GitHub Pages custom-domain file (`CNAME`)
- Privacy and Terms/IP pages
- Contact form that opens the visitor's email application (no form backend required)

## Local preview

Double-click `preview.cmd` on Windows, or run:

```cmd
python -m http.server 8080
```

Then open http://localhost:8080
